## 💡 Quick Reference: Prompt Best Practices

### ✅ DO:
- Provide complete track metadata (genre, BPM, key, language)
- Specify target markets and cultural context
- Include current performance metrics when available
- Define clear collaboration goals
- Request evidence-based cultural insights

### ❌ DON'T:
- Ignore cultural sensitivity concerns
- Skip artist consent for adaptations
- Rely solely on AI for creative decisions
- Overlook IP and rights issues
- Forget to credit all contributors
- Prioritize virality over authenticity

### 📋 Quality Checklist:
- [ ] Track information complete and accurate
- [ ] Cultural context properly researched
- [ ] Target market clearly defined
- [ ] Artist creative control maintained
- [ ] IP and rights properly addressed
- [ ] Revenue splits transparently established
